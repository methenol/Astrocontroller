# How to Use Dual-Camera Astrophotography on Seestar

 Table of Contents

With Seestar’s dual-camera astrophotography feature (available only on the Seestar S30 Pro), you can capture synchronized "telephoto deep-sky imaging" and "wide-field night sky scenes" in one session. Capture nebulae and galaxies while preserving the Milky Way, landscapes, and the full night-sky atmosphere.

**Note**：Dual-camera functionality is currently supported only on the Seestar S30 Pro.

## **1. How to Start Dual-Camera Capturing**
- Open the Seestar App, connect your device, and enter "Stargazing Mode". Select your deep-sky target, complete GoTo, and start stacking images.
- Once stacking starts successfully, return to the home screen and re-enter "Milky Way Mode". Choose between Capture or Time-lapse modes to enable dual-camera shooting.

The telephoto camera continues tracking and stacking your deep-sky target, while the wide-angle camera simultaneously captures wide-field astrophotography footage.

[image: Seestar App home screen showing Stargazing and Milky Way modes for dual-camera astrophotography]

## **2. How to Stop Dual-Camera Capturing**

First enter "Milky Way Mode" and stop Capture. Then return to "Stargazing Mode" and stop Capture.

### **Why Stop in This Specific Order?**
- Stopping Milky Way Mode first allows the telephoto deep-sky capture in Stargazing Mode to continue stacking uninterrupted.
- If Stargazing Mode is stopped first, the wide-angle capture session will also be forcibly interrupted, which may result in incomplete footage from the wide-angle camera.

## **3. Important Notes for Dual-Camera Operation**

### **3.1 Stargazing Mode Acts as the Primary Mode**

You can only enter Milky Way Mode after stacking has started in Stargazing Mode. If Milky Way Mode is already stacking, you cannot simultaneously start a new capture in Stargazing Mode.

### **3.2 Capture Limitations in Milky Way Mode**

#### **Capture**
- Only supports full-resolution output; 8K stitching is unavailable.
- "Freeze Ground" is disabled, as the wide-angle camera must stay synchronized with the telephoto’s tracking mode.

#### **Timelapse**
- Only supports tracking mode (cannot be disabled), creating a "still sky, moving landscape" effect.

#### **Star Trails**
- Currently unavailable during dual-camera capture.

### **3.3 Other Operational Tips**
- Triggering "Re-GoTo" or selecting a new target in Stargazing Mode during dual-camera capture may interrupt wide-angle tracking.
- Dual-camera operation significantly increases power consumption. For long sessions, using an external power supply is strongly recommended.
