# Device reference (read-only, offline)

The Seestar models' documentation: use the pages of the model you run (`seestar_status` → `device.model`); the app guides apply to every Seestar.

Shipped with Astrocontroller and refreshed into this workspace on every start, so **do not edit
these files**: write what you learn into your skills or NOTES.md instead. Search before reading
whole files: `grep -n -i "<term>" reference/**/*.md`, then `read` the lines around the hit.

| File | What it is |
|---|---|
| `seestar-s50-pro-specs.md` | **S50 Pro** one-page specification sheet: optics, cameras, filters, exposure and darks, mount and pointing (the firmware's JNow), power, storage, connections, all with sources, with what was verified on an S50 Pro. **Start here on an S50 Pro.** |
| `seestar-s30-pro-specs.md` | **S30 Pro** specification sheet, the same layout. **Start here on an S30 Pro.** |
| `zwo-help/Seestar-S50-Pro-Product-Page.md` | ZWO's S50 Pro product page with the official specification table and its footnotes (60 s only in EQ mode, battery conditions). |

| `zwo-help/Quick-Guide-to-the-Seestar-App.md` | The app's screens and modes. |
| `zwo-help/EQ-Mode-vs-AZ-Mode.md` | When to use Equatorial Mode and what it changes. |
| `zwo-help/EQ-Mode-Equipment-Setup.md` | Setting the scope up for EQ mode (the equipment). |

All `zwo-help/` pages are copies of official Seestar / ZWO pages (seestar.com, zwoastro.com),
saved 2026-11-13, with the source URL at the top of each. They describe the Seestar app;
Astrocontroller drives the same firmware features through its tools. Where a page and your
verified experience differ, your skills and the spec sheet's [V] entries win.
