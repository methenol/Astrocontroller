## Shooting Method 1: AR Framing

**Tap AR Framing.**

**Enter the Milky Way framing interface.**

The interface will overlay a Milky Way texture in real time based on the device's orientation, displaying the galactic region currently in view.

**Function Overview:**

  1. Locate Milky Way : When the AR Milky Way is not visible in the current view, it means the device is not pointing toward a direction where the Milky Way can be captured. Tap “Locate Milky Way”, and the device will automatically adjust to a suitable direction.

> The system will first evaluate the galactic center altitude: if it is higher than 10°, the device will point to the galactic center; otherwise, it will point to the highest point of the Milky Way plane.

  2. Confirm Framing：Use the joystick to adjust the composition. Once the Milky Way is positioned as desired, tap “Confirm Framing”, and the device will track the current framed area.

  3. Reset Position: If you have manually moved the device, you can use “Reset Position” to recalibrate the current orientation.

> The device determines the Milky Way position based on its current posture and direction. Manual movement may lead to inaccurate positioning. Tap “Reset Position” to recalibrate the current position and direction, and restore accurate alignment.

  4. AR Milky Way Display: Used to toggle the visibility of the AR Milky Way overlay in the view. This helps you observe the landscape for better composition.

  5. Exit AR: Tap to exit the current AR Framing mode. After exiting, the Milky Way overlay will disappear and the interface will return to the shooting screen.

 

> After exiting, to use AR Framing again, you can re-enter it from the toolbox.

**Determine the shooting target: Tap Confirm Framing**

# 4\. Set Parameters

You can choose either of the following methods to complete parameter setup.

## Method 1: Automatic Parameter Settings

For first-time shooting, it is recommended to use automatic parameter settings.

> Note: You need to turn off automatic parameter settings before using Quick Settings or adjusting parameters manually.

## Method 2: Quick Parameter Settings

Quick Settings will match parameters based on existing dark frames.

## Method 3: Manually Set Shutter and Gain

**For the first shot, we recommend a 10s shutter. Use 0 gain for the DWARF 3 and 40 gain for the DWARF Mini.**

> Note: When using longer shutter times, it is recommended to use Equatorial Mode.

# 5\. Tap to Shoot

In Milky Way mode, Photo stacking automatically processes the sky and foreground to create a final image with a stacked starry sky and a fixed foreground.
